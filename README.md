# 大航海傳說 · 船隻強化模擬器（繁體中文版）

對 [ship.pinetop.uk](https://ship.pinetop.uk/)「大航海传说船只强化模拟器」的**繁體中文重製版**。

原站為簡體中文、單一混淆腳本 + Supabase 雲端方案分享。本專案改為：

- 介面與遊戲用語全面**繁體中文**
- 原始碼可讀、可維護（HTML / CSS / JS 分離）
- **本機 localStorage** 儲存預設方案（不依賴原站後端）
- 支援方案 **JSON 匯入／匯出**

## 功能

| 功能 | 說明 |
|------|------|
| 多輪強化 | 每輪**必須選滿 4 個不同零件**，可新增／插入／刪除輪次 |
| 17 種特製零件 | 含橫帆、縱帆、槳力、轉向、抗浪、護甲、船耐加成 |
| 智能填充 | 依所選零件加總該輪最大可強化值 |
| 鎖定 | 鎖定後自動填充不會覆蓋 |
| 累計／拆分 | 輸入框顯示總值或本輪增量 |
| 屬性篩選 | 零件下拉只顯示對該屬性有用的材料 |
| 來源追蹤 | 點屬性縮寫高亮相關零件 |
| 屬性彙總 | 進度條 + 自訂上限 + 自動配優先順序；可開懸浮窗 |
| 強化次數上限 | 限制可新增的強化輪數 |
| 自動配（**本專案原創**） | 只依使用者優先產生多組組合（彈窗＋雷達圖選一回填）；同優先＝一起盡量超限；留白不列入 |
| 本機預設 | 依船種儲存／載入方案 |
| 匯入匯出 | JSON 備份與分享 |

## 船種與資料

- **排船 / 砲船 / 冒險船 / 商船 / 傳奇船**
- 零件與船隻列表自原站腳本解出並轉為繁中用語
- 資料檔：`js/data.js`（亦有一份 `src/data/game-data.json`）

## 本機開啟

直接用瀏覽器開啟 `index.html`，或使用靜態伺服器：

```bash
# Python
python -m http.server 8080

# 然後開啟 http://localhost:8080
```

## 目錄結構

```
index.html          # 入口
css/styles.css      # 樣式
js/data.js          # 遊戲資料（繁中）
js/app.js           # 模擬器邏輯
src/data/game-data.json
README.md
```

## 與原站差異

| | 原站 | 本專案 |
|--|------|--------|
| 語系 | 簡體 | 繁體 |
| 程式 | 混淆單檔 | 可讀原始碼 |
| 方案分享 | Supabase 雲端 | 瀏覽器本機 + JSON |
| 自動配 | 無 | ✅ 原創新增（依優先自動規劃輪次） |
| 部署 | Cloudflare | 任意靜態託管 |
